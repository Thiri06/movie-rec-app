1. APPLICATION OVERVIEW

YOKO Movie Intelligence is a movie recommendation web application that helps users discover movies, view detailed movie information, save favourites, track watch history, and receive personalized recommendations.

The system uses:
- React for the frontend user interface.
- React Router for page routing.
- Firebase Authentication for user login.
- Express.js for the backend API.
- MongoDB with Mongoose for persistent data storage.
- TMDb API for movie search, discovery, details, images, trailers, cast, crew, recommendations, and similar movies.
- Gemini AI for spoiler-free movie insight summaries when configured.

5. RECOMMENDATION SYSTEM FUNCTIONALITIES

Algorithm Type:
- Hybrid recommendation system.

Signals used:
- Favorites.
- Watch history.
- Explicit mark-watched records.
- User interactions such as detail views.
- Genres.
- Cast.
- Directors.
- Similar-user collaborative signals.
- Movie quality signals from rating and popularity.
- Recency of user activity.

Recommendation behavior:
- Favorites receive stronger weight than passive views.
- Marked-watched movies receive stronger weight than normal watch-history views.
- Recent signals receive higher weight than old signals.
- User taste vectors are built from movie, genre, cast, and director data.
- Similar users are found through overlapping favorites, history, and interactions.
- Collaborative candidates are gathered from similar users' favorites, history, and interactions.
- Content-based candidates are gathered from TMDb using the user's top genres.
- Already-seen and already-favorited movies are excluded.
- Candidate movies are scored using content match, people match, collaborative boost, and quality.
- Human-readable explanations are generated, such as:
  - Because you favorited a related movie.
  - Shares actors you like.
  - Matches directors you like.
  - Users with similar taste also saved or watched this movie.

10. USER WORKFLOWS

10.1 Guest Workflow
- Visit Home page.
- Open Demo page to understand the app.
- Go to Login.
- Sign in with email/password or Google.

10.2 New Authenticated User Workflow
- User logs in.
- App syncs Firebase user to MongoDB.
- User opens Profile and saves taste preferences.
- User searches or discovers movies.
- User views movie details.
- Detail views are recorded as watch history and interaction signals.
- User favorites movies or marks movies watched.
- User returns to Dashboard and syncs signals to get recommendations.

10.3 Recommendation Workflow
- User activity is collected through favorites, watch history, marked-watched records, and interactions.
- Backend builds a weighted taste profile.
- Backend collects content-based candidates from TMDb.
- Backend collects collaborative candidates from similar users.
- Backend scores candidates.
- Backend saves top recommendations.
- Dashboard displays recommendations with explanations.

10.4 Content Safety Workflow
- User enters birth date and maturity setting in Profile.
- App calculates age and content limit.
- Discover filters content based on profile safety mode.
- Underage users are automatically restricted.
