Software Requirements Specification (SRS)
1. Project Introduction
The Movie Recommendation Web Application is a dynamic, API-driven platform designed to help users discover movies tailored to their preferences. It integrates real-time data from The Movie Database (TMDb) API and analyzes user interaction patterns to generate personalized recommendations. The application does not support movie streaming at this stage but may include it in future enhancements.
2. Functional Requirements
User authentication via Google Sign-In (Firebase)
Search movies using TMDb API
Browse trending and genre-based movie lists
View detailed movie information
Record user watch history
Generate personalized recommendations based on genre similarity and user behavior
Responsive UI for desktop and mobile
3. Non-Functional Requirements
Secure authentication and data handling
Fast response time for API calls
Scalable backend architecture
High availability and fault tolerance
Maintainable and modular codebase
Cross-browser compatibility
4. System Architecture
Three-tier architecture:
Frontend: React + Tailwind CSS
Backend: Node.js + Express.js
Database: MongoDB
External Services: TMDb API, Firebase Authentication

6. ERD Diagram
Entities:
User (user_id, name, email, preferences)
Movie (movie_id, title, genre, rating, description, poster_url)
WatchHistory (history_id, user_id, movie_id, timestamp)
Recommendation (rec_id, user_id, movie_id, reason, score)
Relationships:
A User can have multiple entries in WatchHistory, each linking to a Movie.
A User can receive multiple Recommendations, each associated with a Movie.
WatchHistory links Users and Movies to record viewing activity.
Recommendations link Users and Movies with additional metadata such as reason and score to explain the recommendation.
Movies can belong to multiple genres, and Users have preferences that influence recommendations.
